# Compressibility Effects: Density vs. Velocity

This section explores how fluid density responds to velocity changes across different Mach numbers using the relation $d\rho/\rho = -M^2 (dV/V)$. 

## Data Overview
The `Compressibility Effects.xlsx` file contains three cases:
*   **Sheet 1:** Velocity change required to achieve a fixed 0.01% density change at very low Mach numbers.
*   **Sheet 2 & 3:** The % change in density for fixed 1% and 6% velocity increases across subsonic and supersonic regimes.
